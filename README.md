# My Portfolio 2

자영업 사장님을 위한 작은 도구 두 가지를 모아 보여주는 포트폴리오 메인 페이지입니다.
파스텔 배경과 멤피스 도형, 평면(flat) 벡터 일러스트 스타일로 만들었어요.

## 프로젝트 카드

| 카드 | 설명 | 이동 경로 |
| --- | --- | --- |
| 메뉴판 | 가게 이름과 메뉴, 가격만 고치면 완성되는 모바일 메뉴판 | `../메뉴판/index.html` |
| 단골 적립 스탬프 | 휴대폰으로 도장을 모으는 적립 카드 | `../단골 적립 스탬프/index.html` |

## 파일 구성

- `index.html`: 화면의 뼈대 (제목, 카드 2장, SVG 일러스트)
- `style.css`: 디자인 (파스텔 색, 멤피스 도형, 카드 효과, 휴대폰 화면 대응)
- `main.js`: 움직임 (카드 등장 효과, 배경 도형이 마우스를 살짝 따라다님)

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 설치할 것은 없어요.

```
start "" index.html
```

## 알아둘 점

카드 링크는 폴더 위치를 기준으로 합니다. `메뉴판`, `단골 적립 스탬프` 폴더가
`My-Portfolio2` 폴더와 같은 위치(옆 폴더)에 있어야 이동돼요.
인터넷에 공개할 때는 각 프로젝트의 공개 주소로 링크를 바꿔 주세요.
